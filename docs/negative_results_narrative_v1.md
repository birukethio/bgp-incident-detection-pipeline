# Negative Results Narrative v1

The negative results matter because they reduced the plausible model space. Stage 1 did not become the final architecture, domain experts were not adopted, threshold tuning was not sufficient, and class balancing alone did not solve the task. Random Forest remained useful as a benchmark, but XGBoost and then K1 stacking produced stronger TRAIN-only evidence. These outcomes support the final model-selection rationale without hiding unsuccessful paths.
