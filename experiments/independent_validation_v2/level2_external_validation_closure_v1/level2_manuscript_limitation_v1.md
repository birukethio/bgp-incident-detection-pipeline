# Manuscript Limitation Paragraph v1

An additional source-separated external confirmation of the final Level-2 temporal stacker was designed but not executed. The implementation-recovery audit reproduced the pipeline through window construction, V4 feature generation, Level-1 XGBoost probabilities, mean aggregation, and Level-2 temporal meta-feature construction exactly on deterministic TRAIN fixtures. However, the original trained Level-2 XGBoost object was not persisted as a recoverable binary artifact. Historical code fitted the Level-2 model in memory from TRAIN meta-features using the frozen YAML configuration and then wrote predictions and result summaries rather than the trained model object. Refitting Level 2 after the external roster existed was avoided to preserve the external-validation boundary and to avoid representing a newly fitted model as the original frozen model. Therefore, the dissertation does not claim source-separated external confirmation of the Level-2 stacker; the existing TRAIN nested/grouped-CV and historical Final Holdout evidence remain unchanged.
